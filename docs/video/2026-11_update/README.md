## 音轨

源文件 `assets/1030-movie/音频 1_2.wav`（126.207s，48kHz 立体声，pcm_f32le）。
处理链写在渲染器的 `build_audio_chain()` 里，一条 ffmpeg `-af`：

高通 85Hz 去低频轰鸣 → `afftdn` 自适应降噪 → `anlmdn` 抹残余宽带嘶声
（实测底噪 2–6kHz 最重） → 320Hz 减箱音、3kHz 提清晰度 → `deesser` 压齿音
→ 轻压缩收动态 → `loudnorm` 归一到 -16 LUFS → `alimiter` 限幅。

结果：−15.8 LUFS / LRA 3.9 LU / 峰值 −0.8 dBFS。原始底噪约 −42.7 dBFS，
处理后语音余量从 19.0 dB 提到 23.8 dB。

## 时间轴与字幕

**字幕不是写出来的，是转出来的**：用 faster-whisper（small 模型，词级时间戳）
对着降噪后的音轨转写，拿到每句话的起止，再按语义校正错听的同音字
（「屏空」→ 凭空、「普速」→ 朴素、「创新工坊」→ 创意工坊、「一九五百多年」→ 一局五百多年）。

镜头边界全部落在语音段落的静音处，用**帧号**写死（`SCENE_FRAMES`），
整片帧数之和 = 音轨长度，渲染前有断言把关。改时长就改这一张表。

字幕首尾会做一次贴边（`_snap()`）：溢出到切换点后 0.3s 内、或早于切换点 0.35s
以内的，收进单页；判断一律换算成帧号，避免 `79.233` 与 `79.23333` 的浮点误差。
渲染前 `_check_subs()` 会查重叠、倒挂、超长、读不完。

## 视觉基调

暖纸底（`#F6F2E9`，带极轻暗角与纸纹噪声）、深墨正文、朱红强调、赭金小标签。
标题用思源宋体（`NotoSerifCJK-Bold`），正文与数字标签用思源黑体，
页眉的小标签用逐字加字距的手排方式，避免整片只有一种字体在说话。

页眉只有一个实现：左侧红色竖标 + 字距小标签（如「机制 · MECHANICS」）+
衬线大标题，右侧圆形作品图标，下面一条细线加一段朱红短线收口。
页脚是细进度条（随全片时间推进）、作品署名与 `03 / 14` 页码。

图片素材一律只做等比缩放和淡入上浮，不加滤镜、不加裁切放大——图片本身

## 时长微调

## 转场

镜头之间 8 帧交叉溶解（`XFADE`），页眉保持不动、只有内容变化，切换不生硬。

## 渲染命令

```bash
python3 scripts/video/render_update_2026_11.py --probe     # 每镜头抽 3 帧 + contact_sheet3.png
python3 scripts/video/render_update_2026_11.py --render    # 全片（音轨缺了会自动做）
python3 scripts/video/render_update_2026_11.py --render --fresh --only 7-10   # 重渲指定镜头
```

`_probe_ok()` 的时长容差是 **0.05s**，不能再放宽：镜头时长彼此只差零点几秒，
容差一大就会把旧时长的片段当成合格跳过，成片与音轨错位。
`--fresh` 会连音轨一起重做。

合成时必须**去掉 `-shortest`**：AAC 编码后音轨时间戳会比画面略短，
`-shortest` 会按最短的流截断，成片凭空少掉几秒。

沙箱里 `build/segments_v3/` 的文件删不掉（Operation not permitted），
所以渲染器不清理旧片段，只按显式 `list.txt` 拼；`--fresh` 用 ffmpeg `-y` 覆盖。
单机约 30–45s 渲一段，整片 6–8 分钟；一次 bash 调用可能超时，分批 `--only` 续渲即可
（已完成的段落靠 `_probe_ok` 自动跳过）。

## 已知约束

- 每个镜头的静态底板（纸、页眉、截图）在 `base()` 里只构建一次并缓存；
  **动态内容不能进缓存**——图表曾把整块缓存导致曲线冻在第一帧。
  投影按尺寸单独缓存，这是逐帧渲染里最贵的一步。
- 这台沙箱是 2 核 3GB，whisper `medium` 模型跑不完（3 分钟也转不完 126 秒音频），
  复核文本要用切片段的方式；`small` 的词级时间戳是可用的。
- 文字一律走 `wrap()` 折行并修孤字；说明栏高度由 `_notes_plan()` 预算，
  与左侧图片竖直居中，不靠目测。
