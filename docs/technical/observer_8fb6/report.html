4. 物资供应：当前开工规模总体能供，局部市场有缺口

1840 世界建材实际生产 5,015.84，市场登记的建筑需求 4,080.41，建筑实际取得 3,994.34，相差 86.07，取得率 97.9%。这些按市场字段汇总；未把跨市场贸易重复计作世界生产。138 个有建材需求的市场中，5 个供给小于需求。

末档 89 个施工项目中，3 个工地有明确建材缺货量，0 个有工具缺货量；4 个项目的月度缓存记录物资进度扣减。全时期分别为 168 条明确建材短缺、157 条明确工具短缺、169 条缓存物资扣减，快照时差使这几项不完全对应。

局部例子：阿涅洛 anelo 工地 8 级满员，当地建材市场供给 28.15、需求 87.29，工地缺货字段 65.90，月度进度仍为 5,963.3；工具和建材满足率按平均值计算，建材严重短缺不会独自将进度归零。

不能据此保证全面复工供给无忧：489 级工地全部满员时，未修正的基础建材需求为 9,780，远高于当前 5,015.84 的生产。现有闲置工坊能否同步恢复、以及新版模块和落成建筑新增的持续需求，都需另测；当下供给相对充足与工地低开工率共同存在。

5. 财政影响：局部负担很重，未建立全局崩溃的因果证据

财政使用 economy.recent_balance 最后一个已实现结余，并逐档核对收入−支出；全部已提取国家记录均一致。工程负担取国家拥有的工地、模块、未仪式实体和落成奇观建筑保存的 upkeep 之和。工坊利润属于生产部门收益，不能直接加回国库。

当前驱动器只主动按固定目标建营；没有主动按市场缺口协调工坊、重新开启已关闭工地，或因长期无效续建更换候选的逻辑。因此许多现象符合原先“允许失败、物资交给原版 AI”的简化策略，却不满足“可持续、高利用率建设”的效果预期。

  1. 先加持续预算约束。接受项目、扩营和重新开启工地前估算实际月维护，结合国库缓冲、债务与剩余支持度决定可承担营地数；不要只提高固定 300 门槛。
  2. 把关营和重新开启纳入同一项目决策。区分暂时财政紧张、当地招聘失败和真正的市场缺货，满足条件才重新开营，避免原版 AI 与工程驱动器反复拉扯。
  3. 限制无效续建循环。优先候选加入近期推进、可用劳工和可承担成本条件；升龙、里斯本可作为定向回归样本。
  4. 按市场缺口协调供给。先检查工坊是否关闭或缺工，再决定扩建。此局没有证据支持普遍继续加盖工坊。
  5. 新维护规则另开观察者验收。确认模块、实体和最终建筑实际使用新版方式，再观察长期建材需求与财政负担；同时补足可轮转的逐月诊断日志。
