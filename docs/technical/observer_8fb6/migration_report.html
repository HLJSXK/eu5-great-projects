施工常驻 +2 移民吸引力：对有迁徙权国家偏强

补查后的判断是：应收紧。它能够填补部分用工，但目前在没有建成营地、营地关闭、当地已有大量闲置人口时仍持续生效，已出现显著的人口集中和与工地岗位脱节的迁入。对所有国家无条件适用的结论不成立；本报告严格排除了没有平民迁徙权的国家。

筛选：逐档检查国家 government.implemented_privileges 当前是否有 peasants_free_peasantry，原版中文名正是“平民迁徙权”，同时允许农民和劳工迁徙。只统计这些国家中的施工地点及同国对照。没有该特权，即使另有允许迁徙的机制，也不纳入。本次覆盖 52 档、1195 条有权国家的工地观察；末档为 57 个工地。

“本国迁入量”是该国所有地点记录的农民、劳工 MigrationIn 之和，包含国内迁移，不等同于外国移民。较小流量也能占高份额，因此同时报告绝对人数；没有把所有“占比过半”都当成大规模人口转移。

在有同国、同地点等级、无施工加成对照的 1131 条观察中，工地农民和劳工登记失业率中位数为 72.8%，各工地对应对照组中位数的中位数为 52.0%。两边本来都可能有高失业，差异属于观察性关联，不是 +2 导致失业的净因果效应。

所观察迁入流量中，农民占 84.4%，劳工占 15.6%。这是各快照当月流量的合计占比，不能当作五百年累计迁入。很多迁入者尚未成为营地所需劳工；“吸来人口”并不等于“及时补齐岗位”。

配对要求地点在相邻两档归属同一国家，且国家在两档都持有平民迁徙权；对照地点要求归属和等级稳定、两档都没有施工加成。持续施工组进一步要求加成开始日期完全相同。表中两列增长中位数之差不等于逐对增长差的中位数。

天台的持续窗口：1820 → 1830 → 1840 总人口为 45.69 → 50.30 → 66.15 万；后一十年增长 31.5%，同国同等级的临海、乐清、双溪分别为 +2.36%、−2.22%、+0.18%。同期三个对照地点的增长中位数为 +0.18%。这一窗口始终保存相同施工加成起始日期，支持长期集中现象，而不是只存在开工一两个月的瞬时峰值。

以上不是随机对照试验。初始就业、建筑、首都地位、战争、灾害及其他加成没有全部匹配；两档之间的特权变化、短期工程也不可穷尽。可以据此判断当前规则存在明显的过强与配置失当风险，不能精确估计“取消 +2 后会减少多少人口”。

4. 机制定位：强度与退出条件都需要收紧

当前定义是 local_migration_attraction = 2，是固定数值加成，不能写成“增加 2%”或“实际迁入翻倍”。作为参照，原版“鼓励迁徙”内阁行动的地点吸引力为 +1，并另有全国迁徙速度 +50%；这里只能说吸引力数值是其两倍，不能说两者完整效果等价。

脚本在选定施工地点、进入阶段 3 时立即施加，期限为永久；建营队列是否完成、营地是否开放、是否缺劳工、失业率都不是条件。完成施工或清理项目才移除。全部合格样本中，发现的施工吸引力修正都对应当前活动工地，未见遗留在非活动地点的修正。因此本局的问题主要是活动阶段内无条件保留，而非完工后清理漏掉。

  1. 先绑定真实用工缺口。只在已建成且开放的营地确实缺少劳工时提供吸引；没有营地、主动关营、当地已有可用闲置劳工时归零或显著衰减。
  2. 改为随缺口收敛。接近满员后逐渐降低，避免补齐岗位后仍维持固定 +2。农民大量聚集但转职不足时，应处理转职与就业约束，继续吸人不能代替它们。
  3. 下调幅度做对照。可将 +0.25、+0.5、+1 与现行 +2 作为同一存档的试验档位，先看开工后 12—24 个月的净迁移、劳工入职及迁出地生产就业。它们是待测试档位，本次没有证据选出唯一最优值。

判断：有平民迁徙权时，现行“整个施工阶段常驻 +2”偏过火，尤其在尚未建营和已经停工的项目上。只把 2 改小能减轻强度；按岗位需求启停更直接地针对本次观察到的问题。

5. 证据与复现

原始存档只读。实际人口逐一连接地点的 pop ID 与人口数据库 size，单位从千人换算为人；不使用 population_ratio 代替实际人数。迁入迁出取农民、劳工各自保存的 changes.MigrationIn/MigrationOut，与自然增长、转职分列。失业率取保存的两类 unemployed 之和除以当前实际人口，可能存在月内缓存时差。

所有快照都在四月一日；观察条目会重复包含同一国家和工程，不是独立项目数。记录中的当月流量不代表十年累计，人口增长也不能全部归因于迁移。
