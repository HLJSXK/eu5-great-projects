# 君士坦丁堡建筑与人口就业核对

日期：2026-10-21。档案：`9d1f3b46-96b1-4b41-b187-64b68248ff7e`，地点 `5872 / constantinople`，全部 52 个快照。

**结论：大量建筑确实缺乏雇员，且问题跨越多个用工阶层。1680 起多个快照完全没有劳工（laborers）人口，足以解释这些时点劳工营和其他劳工建筑的零就业。1840 的普遍低就业仍然存在，本国建筑没有显式关闭标记。**

## 统计口径

- 人口从地点的全部 `pops` 引用回查 `population.database`，按实际 `type` 和 `size` 求和；全部人口引用均已解析。没有把 `population.pop_stats.population_ratio` 当作实际人口数。
- 建筑从 `building_manager` 按地点筛选，保留全部所有者；以下汇总只统计地点所属国的已建建筑，排除外国商馆。每条建筑记录合并了同类建筑的多个等级，不等于一个建筑等级。
- “名义岗位”是当前本地原版/ED 定义的 `employment_size × 已建等级`，所有涉及的建筑定义均已解析；“实际雇员”直接读存档 `employed`，缺省为零。名义用工率不是游戏中实时查询的 `building_employment_size_amount`，不把它当作所有潜在修正后的精确岗位数。
- 以不足名义岗位的 90% 统计明显未满员，仅用于描述规模，不是游戏规则中的缺工阈值。`open=no` 单独归为明确关闭；字段缺省保留 `omitted`。
- 人口和雇员保留原始存档单位，不自行换算成界面显示的人数。

## 人口变化与判断边界

实际劳工人口在 1600 为 12.46186，1670 为 6.13153；1680—1780 所保留的每个十年快照均为 0。1790、1800、1810 分别仅为 0.06471、0.02122、0.00128，1820 一度回升至 1.77449，1830、1840 又为 0。因此不能把整个期间说成连续零劳工，但劳工缺失或极少的情况持续出现在多个快照中。

城市总人口从 1600 的 72.51028 降至 1840 的 22.73957，仅为前者的约 31.4%；本国已建建筑条目同时从 53 增至 64。实际人口下降与建筑岗位存量扩张相伴，支持城市层面的供需失衡判断。

圣索菲亚在 1670 时虽有劳工人口，相关劳工建筑仍零就业；该时点还需检查 RGO、其他就业占用或资格条件，不能用 1680 的零人口解释此前所有月份。本次也没有还原人口下降的具体原因（死亡、迁移、转职等），不把城市缺工进一步归因于某个未核对的机制。
