# ED 仪式重写实现与验收记录

日期：2026-10-23。依据 `docs/design/Wonder_Ritual_Rework_Implementation_Plan.md` 与 D01–D38 已定决策；实施中的缺口按本轮“自行决策、不询问”的授权处理。

## 实现结果

- 56 个通用机制、135 个独特奇观，共 191 个单一成品；573 个国家仪式 modifier、191 个地点仪式 modifier。独特奇观继承所属机制的三套奖励、方向和阶层偏好，仅保留自己的三套双语名称和说明。
- 仪式统一 24 个月，确认收取 small / medium / large 对应 2 / 3 / 5 倍 scaled gold。确认时结算现有参与阶层的满意度（支持 +0.10，反对 −0.05）；完成时发放奖励、20 点方向移动与 0.1 月度倾向。倾向不再位于基础效果中，也不随等级或独特倍率放大。
- 168 个方向与 56 套阶层偏好已按既有仪式主题逐项编排。时代轴方向 55，其余 113（其中 2 个属于带 allow 条件的轴）；无条件方向 111。内容是本轮玩法裁定，不冒充额外的史学核验。
- 空壳、朴素、完整状态独立于项目状态。朴素保留完整基础效果与正常落成奖励；主动朴素落成时所有参与阶层反对。开局历史奇观与外部新建保持朴素。
- 地点 / wonder id 的仪式状态只由 grant / revoke 写入。易主、最后一级拆毁与淡忘撤销仪式；部分降级保留。同类型同风格多实例的国家效果去重，失去最后一个来源才撤销。独特奇观同步直接查询固定地点，通用奇观仅在生命周期同步时查询拥有地点。
- 记忆 map 的令牌保存 36500 天，隐藏地点事件延迟 36501 天；旧计时器不能撤销后来重新授予的仪式。淡忘通知使用事件链保存的奇观 / 风格值，避免同一天多座奇观的通知互相覆盖。
- 朴素落成和淡忘直接补充当前国家的单个缓存键，并保留同类型实例的最高等级。落成同时补充全国基础效果的等级最大值；淡忘只读取当前地点该成品的 6 个等级分支。重新仪式化收尾不触发整表重建。月度刷新仍在既有拥有地点遍历中重建两张表；失效条目由月度清除，锁定事件再次校验。缓存补充的开销与拥有地点数量无关，通用仪式 revoke 的国家效果去重查询仍会查询拥有地点。
- 完整奇观扩建直接落成，保留原仪式与期限，不重复发放仪式即时奖励；朴素奇观扩建重新选择。空壳续建不必增加一级即可宣布完工。
- 重新仪式化使用模式 3：严格要求 stage 0 且构思正在进行，选择缓存中等级最高的合格实例，隐藏事件再次验证。完成仅发仪式奖励与 10 威望，随后构思从零开始。确认前可免费取消；确认后可通过放弃项目中止，不退款，也不追加工程师 / 阶层 / 威望处罚。目标最后一级在过程中被拆毁会自动取消，避免 AI 卡在无目标项目。
- 仪式阶段国内支持度不衰减、不触发支持度归零崩溃。AI 选对齐度最高的风格，同分取较小编号；不能付款等待 24 个月后朴素落成，重新仪式化则取消。自主重新仪式化还检查对应规模的付款能力。

## 界面与消费者

工程部采用 B 卷宗式组织。2026-10-23 GUI 改进后，三种仪式与朴素组成四行选择列表；选中行显示金色边线、暖色底与勾，原生完成效果、双半价值观轴和两列阶层卡只展示一份详情。朴素点选仅预览，底部唯一主按钮再执行结算；重新仪式化隐藏朴素，并把取消入口放在模式横幅右侧。卡片直接调用实际执行的 `tv_wonder_ritual_apply_choice_effect`，费用单独调用实际的 `tv_wonder_ritual_pay_effect`；满意度属于确认按钮的原生效果提示，不混入完成奖励。完整奇观扩建的落成期间不显示仪式选择。

进行中仅显示已锁定风格、24 月进度和详情展开开关，操作指引同步切换；建设卡在建成后默认折叠，展开时保留建设详情，已失效的宣布完成按钮隐藏。支持 / 反对计数、奖励类别和当前选中轴来自生命周期缓存，GUI 不扫描地点。已完成仪式显示永久生效摘要，朴素显示重新举行仪式决议的入口说明；不显示淡忘计时。

地点窗口读取地点仪式状态，显示空壳 / 朴素 / 风格名；空壳不展示完整成品的基础效果。保留了地图上通用 / 独特奇观的等级缓存以及现有兼容子模组的覆盖生成。

百科列出三套名称、说明、原生效果、方向与阶层偏好。目录没有活动项目，因此单独按同一奖励数据生成只读演示效果，并注明地点效果以首都演示；实际仪式卡仍渲染真实完成效果。静态图鉴已重建全部 191 条记录，双语方向和阶层偏好不会显示为原始对象字符串。

编辑器已改为三类可组合奖励、方向和阶层偏好字段；独特奇观有 12 个 `ritual_text` 字段，继承的机制只读。规则表只读。费用奖励目录不再改写独特奇观，也不再与 `unique_wonders.yaml` 共用保存基线。

英 / 简中仪式内容完整。现有 11 种语言的动作消息、流程说明和设置语义已对齐；非主语言的新增长说明使用英文。旧八阶段、法罗斯 / 圣索菲亚专属流程、附属仪式建筑、旧价格与监听器、独特仪式设计数据及浏览器已退役，不提供旧 schema 或旧存档迁移。规范本地化中每种主语言残留的 606 个旧仪式键已删除并重生成；九种派生语言通过翻译工具的离线 `--prune-only` 清理，每种删除 606 个旧仪式键和另外 67 个英文源已退役的键，保留其他现有译文。仍被界面引用的通用 `TV_ENGINEERING_CEREMONY_*` 标签保留在手写本地化文件中。

## 游戏内未实测的边界

本轮没有取得实际游戏运行 / 存档 / 多人观测记录。M01–M09 仍需游戏内验收，包括 map 时限与延迟地点事件跨读档、36500 天的日历含义、价值观冲击与净推力、选项很多时的事件 UI、永久提示、易主回调顺序以及联机 / 性能。静态检查、离线渲染和脚本契约测试不能代替这些记录。

**P2-02 / M05 保持未验收。** D27 的单事件方案保留：`.2001` 有 191 个候选选项，另有“稍后”。通过标准是玩家能滚动到每个候选、看清并点击，包括末项；任何候选不可见或不可选均为失败，无报错不代表通过。方案 §17.3 已补充至少 12 个候选与最大集、候选 ID 对照、中英语言、分辨率和 UI 缩放组合、首尾锁定与最高等级实例检查的实机步骤。当前没有实机滚动、截断或选择覆盖证据。
