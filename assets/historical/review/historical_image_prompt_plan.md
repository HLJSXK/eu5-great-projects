# 伟大工程图生图：主体保真，环境与取景开放

当前 140 条独立提示词覆盖全部伟大工程（第 1–20 条为首批自选源图，第 21–40 条为维基共享资源第二批，第 41–136 条为维基共享资源第三批，第 137–140 条为 2026-10-24 新增工程，来源见 `new_wonders_web_sources_20261024.json`），完整英文文本见同目录
`historical_image_prompts.json`。它们不是四张现有输出的生成记录；改写前
的提示词与评估记录保存在 `baseline_v1/`。

主体保留的是身份、标志性轮廓、真实比例与结构关系，而非照片逐像素构图。
允许模型增删或移动非主体植被、路径、天空、云雾、少量时代相符的小人物和
生活物件；允许在同一可辨认视面内轻微降低机位、靠近或调整角度，使主体更突出。
不再锁定原图空白区域、人物数量、背景位置或宽高比。主体必须完整、突出，
可通过尺度参照、空间纵深与整体明暗组织体现人类工程的伟大。

壮观性不通过拉伸主体或复制建筑实现。模型不应自行添加主体塔楼、宫翼、
巨型阶梯或著名地标。实际题材不符、年代未核实的素材仍保留明确限制；
这些限制约束主体身份，不妨碍环境与画面表现的自由。错题材不靠补人物来纠正。

绘画方向明确为**油画质感的卡通插画**，并在每条提示词开头声明。
风格须在缩略图上立即可见：建筑、树木、云和地面用概括的形状与大色块构成，
明暗归并为少量清楚的亮、中、暗层次；轮廓和建筑转折使用有粗细变化的选择性描边，
远景边缘适度融入背景。窗格、砖瓦和树叶以成组节奏与少量笔触暗示，避免逐个写实刻画。
宽刷笔触、断续颜料和少量厚涂高光须融入形体；采用赭石、陶土红、低饱和绿和蓝灰暗部，
保留建筑的厚重、庄严与真实比例，小人物概括成清楚的手绘剪影。

避免摄影级微细节、平滑喷绘、光滑三维渲染、通用电影概念图质感、全画面粗黑描边、
幼稚夸张比例，以及仅覆盖褐色滤镜或画布纹理。油画感和卡通感来自造型与绘制方式。
主体与构图边界沿用此前方案。

**粗笔修订（当前生效）**：首轮输出暴露出模型默认会把树林、草地、人群、砖石和水波画得过细。现行共用段落改为“宽而粗的鬃毛笔”设定：最小笔触约为画宽的 1/80，比这更细的东西不存在；细节只花在主体轮廓和大的结构分段上，形体内部只允许两三笔变化。并逐项规定画法：树林是两三种绿色的几团大色块，草地是带几道方向笔触的大色面，砖石碎石是大块切面，水面是平涂色带加几笔高光，人物是一两笔剪影且成组合并，窗、瓦、雕刻、壁画只用一串色点暗示。构图段改为“陪衬宁可删、不可多”，人物至多几处；结尾增加 200 像素缩略图自检。第 21–40 条主体段落同步改写，为各图的高细节区域（林坡、碎石、人群、水面、天顶壁画等）写明粗笔画法。修订前全文见 `before_coarse_brush_revision/`。风格修改前的提示词见 `composition_v2_before_style_revision/`。
无需把每一种可选陪衬都加进画面。
